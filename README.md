# DevOps Web App Automation

This repository contains a simple frontend web application set up to demonstrate **End-to-End DevOps Automation** using:

- **Continuous Integration (CI):** Automated builds using GitHub Actions
- **Continuous Deployment (CD):** Automatic deployment to Netlify/Vercel on code push
- **ChatOps Notifications:** Real-time build and deployment alerts via Slack or Microsoft Teams
- **Version Control Workflows:** Git-based branching, commits, and pushes
- **Cloud-based Static Hosting:** Global distribution via CDN

## Features
- Automated build pipeline triggered on every commit
- Real-time notifications for build success/failure
- Instant deployment of updates to production URL
- Easy-to-understand project structure (HTML/React/Angular)

## Purpose
This project simulates a real-world DevOps environment to teach students:
- How to configure CI/CD pipelines
- Integrate collaboration notifications (ChatOps)
- Deploy static websites globally
- Apply DevOps best practices in a controlled lab setup

## How to Run
1. Clone this repository
2. Make changes to the web app
3. Push changes to GitHub
4. Observe automated build, Slack notification, and redeployment

## Tech Stack
- Git & GitHub (Version Control)
- GitHub Actions (CI/CD)
- Slack / Microsoft Teams (ChatOps)
- Netlify / Vercel (Static Deployment)
- HTML / React / Angular (Frontend)
